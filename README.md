## 🚀 Featured Projects

### 1. SupportPilot — *AI Customer Support Platform*

> A multi-tenant support platform where customers, agents, team leads and org admins work in isolated organizations, with an AI assistant grounded in each organization's own documents.

`Next.js` `TypeScript` `Node.js` `Express.js` `PostgreSQL` `MongoDB` `Redis` `Socket.IO`

- Multi-tenant architecture with 4 roles (Customer, Agent, Team Lead, Org Admin) and access checks that keep each organization's data isolated
- Real-time chat with typing indicators, presence and read receipts; PostgreSQL for transactional data, MongoDB for conversations
- RAG pipeline: document ingestion → chunking → embeddings → vector search, so answers draw on each org's own knowledge
- AI assistant that looks up and creates tickets through permission-checked APIs, with confirmation before any high-risk action

[📂 View repositories](https://github.com/19kumarashish?tab=repositories)

### 2. Reliable Webhook Delivery Service

> A webhook platform that accepts application events and delivers them to subscribers asynchronously, with retries and idempotency.

`Node.js` `TypeScript` `Express.js` `PostgreSQL` `Prisma` `Redis` `BullMQ` `Docker`

- REST APIs to register webhook endpoints and ingest events, validated with Zod
- Relational schema for events, subscriptions, delivery records and full delivery-attempt history
- Background delivery via Redis + BullMQ with configurable retry policies
- Event-to-subscription matching, idempotency-key storage and cryptographic webhook secret generation
- Docker Compose setup for PostgreSQL and Redis
